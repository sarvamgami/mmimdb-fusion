# Multimodal Movie Genre Classification on MM-IMDb

Predicts all genres of a movie (23-way multi-label) from its **poster** and **plot summary**, and
compares unimodal baselines with **five fusion strategies**: early fusion, late fusion,
intermediate (two-tower concatenation), modality attention and the Gated Multimodal Unit (GMU).

| Component | Choice |
|---|---|
| Dataset | MM-IMDb (Arevalo et al., 2017), official train/dev/test split (15,552 / 2,608 / 7,799) |
| Image encoder | EfficientNet-B0, ImageNet weights, frozen, 1280-d pooled features |
| Text encoder | BERT-base-uncased, frozen, mean-pooled over non-padding tokens (768-d); `[CLS]` kept for ablation |
| Loss | BCE with logits, per-genre `pos_weight = sqrt(neg/pos)` |
| Training | AdamW, lr 1e-3, weight decay 1e-4, dropout 0.3, batch 128, early stopping on val loss (patience 10) |
| Decision | Per-genre thresholds tuned on the validation split |
| Evaluation | micro / macro / weighted / samples F1, mAP, Hamming loss; mean ± std over seeds 0, 1, 2 |

## Repository layout

```
src/
  config.py      all paths and hyperparameters
  data.py        loading, data-quality summary, leakage-free de-duplication
  features.py    frozen EfficientNet-B0 / BERT feature extraction (cached)
  models.py      unimodal, early fusion, intermediate concat, modality attention, GMU
  train.py       training loop, class weighting, early stopping, seeding
  evaluate.py    multi-label metrics, threshold tuning, late fusion, subgroup analysis
  experiment.py  runs all models x seeds, ablations, summaries
  plots.py       every figure in the report
notebooks/
  run_all.ipynb        end-to-end pipeline (generated by build_notebook.py)
results/
  figures/  tables/    outputs written by the notebook
tests/
  make_fake_mmimdb.py  tiny fake dataset for an offline smoke test
```

## Reproduce

### Option A: Google Colab (recommended, free T4 GPU)
1. Open `notebooks/run_all.ipynb` in Colab (`File → Open notebook → GitHub`, paste this repo URL).
2. `Runtime → Change runtime type → T4 GPU`.
3. In the first code cell set `REPO_URL` to this repository.
4. `Runtime → Run all`. It mounts Google Drive (features are cached in `MyDrive/mmimdb_cache`),
   downloads MM-IMDb (~8 GB) from `https://archive.org/download/mmimdb/mmimdb.tar.gz`,
   and writes every figure and table to `results/`.

Runtime on a T4: download + extraction ~15–25 min, feature extraction ~25 min, training all
models, seeds and ablations ~10–15 min.

### Option B: local GPU
```bash
git clone <this repo> && cd mmimdb-fusion
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt jupyter
mkdir -p data && wget -c https://archive.org/download/mmimdb/mmimdb.tar.gz -O data/mmimdb.tar.gz
tar -xzf data/mmimdb.tar.gz -C data            # creates data/mmimdb/split.json and data/mmimdb/dataset/
cd notebooks && jupyter nbconvert --to notebook --execute run_all.ipynb --output run_all_executed.ipynb
```

### Offline smoke test (no GPU, no download)
```bash
python tests/smoke_test.py
```
Builds a 300-movie fake dataset with random features and runs the full notebook logic.

## Reproducibility
- Fixed seeds (0, 1, 2) for weight initialisation and batch order; every number is mean ± std.
- Feature standardisation, class weights, late-fusion weights and thresholds use only train/validation data.
- The test split is used once, for reporting. Model selection uses validation macro-F1.
